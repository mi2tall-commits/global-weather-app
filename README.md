# 🌍 글로벌 앙상블 종합 날씨 예보 웹 애플리케이션 (Global Ensemble Weather App)

전 세계 최고 권위의 다중 기상 예측 모델(유럽 **ECMWF IFS**, 미국 **NOAA GFS**, 독일 **DWD ICON**, **대한민국 기상청 GDAPS**, 캐나다 **CMC GEM**)의 수치예보 데이터를 실시간 앙상블 종합 분석하여 제공하는 반응형 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **📍 GPS 자동 감지 & 전 세계 실시간 위치 검색**
   - 브라우저 원클릭 GPS 위치 인식 및 한국어 상세 행정구역 역지오코딩
   - 전 세계 도시/지역명 실시간 자동완성 검색
   - 자주 찾는 장소(집, 직장 등) 즐겨찾기 저장 및 빠른 전환

2. **🤖 다중 글로벌 기상 모델 앙상블 종합 판정**
   - ECMWF, GFS, ICON, KMA GDAPS 등 다중 모델의 강수 예측치를 지능형 가중치로 종합
   - 복잡한 모델별 수치 나열 대신 **단일 종합 브리핑과 모델 신뢰도(일치도)**를 명확하게 제시

3. **📅 최대 16일 중장기 예보**
   - 오늘부터 16일 뒤까지의 일자별 최고/최저 기온, 날씨 상태, 강수 확률(%), 일 강수량 제공
   - 일자 탭 클릭 시 해당 일의 시간대별 세부 예보로 즉시 연동

4. **⏱️ 1시간 / 3시간 간격 세부 타임라인**
   - 1시간/3시간 단위 전환 가능한 타임라인
   - 시간대별 기온, 날씨 아이콘, **강수 확률(%)**, **예상 강수량(mm)** 시각화 바 차트

5. **🎯 생활 & 외출 맞춤 가이드 카드**
   - **우산 지수**: 강수 확률 및 강수량 기반 우산 소지 필요 여부 가이드
   - **옷차림 추천**: 기온대별 최적 옷차림 (반팔, 자켓, 코트, 패딩 등)
   - **세차 / 빨래 지수**: 3일간 강수 예측 연동
   - **야외 활동 지수**: 비, 강풍, 폭염 조건 연동
   - **미세먼지 / 대기질**: PM10, PM2.5 대기질 등급 실시간 표시

6. **⚠️ 기상 특보 & 재해 예방 알림**
   - 호우주의보, 강풍, 폭염, 한파 조건 감지 시 상단 경고 배너 표출

7. **⚡ Google Apps Script (GAS) 매일 아침 브리핑 자동 발송**
   - `gas/weather_notifier.gs`를 통해 매일 아침 이메일(Gmail) 또는 텔레그램으로 자동 브리핑 수신 가능

## 🚀 GitHub Pages 배포 방법 (1분 소요)

별도의 백엔드 서버나 DB 없이 GitHub 저장소에 푸시만 하면 즉시 무료 호스팅됩니다.

1. 본 폴더의 파일들을 GitHub 저장소(예: `global-weather-app`)에 업로드/푸시합니다.
2. GitHub 저장소의 **Settings** 탭으로 이동합니다.
3. 좌측 메뉴에서 **Pages**를 클릭합니다.
4. **Build and deployment** 섹션의 Source를 **Deploy from a branch**로 선택하고, Branch를 **main / root**로 설정한 뒤 **Save**를 누릅니다.
5. 1분 후 `https://<당신의GitHubID>.github.io/global-weather-app/` 주소로 즉시 전 세계 어디서나 접속 가능합니다.
